## 2. Поля карточки (готовые значения)

### Название — до 30 символов
> **Орбита: неоновый забег**  (22 символа, `texts/name-ru.txt`)

Дублируется латиницей при желании — «Orbita: Neon Orbit Runner» (25).

### Краткое описание — до 80 символов
> **Неоновая аркада: веди комету по орбитам, уклоняйся и бей рекорд**  (63 символа, `texts/short-ru.txt`)

Альтернатива (59): «Орбиты, кристаллы, метеориты: неоновый забег в одно касание» — `texts/short-ru-alt.txt`.

### Полное описание — до 4000 символов
> Файл: **`texts/description-ru.txt`** — 2095 символов, 33 строки.

Первые ~700 символов — самое важное: RuStore сворачивает описание, и в карточке видно только начало.
Структура: как играть → что в игре → про рекламу и подарки → настройки и язык → техническое.

### Что нового (для версии 1.1.0)
> Файл: **`texts/whats-new-ru.txt`** — 501 символ.

### Локализация
Основной язык — русский (обязателен). Английские тексты — в `texts/*-en.txt`;
RuStore позволяет добавить локаль en, но модерация смотрит русскую карточку.

### Категория
**Игры → Аркады** (запасной вариант — «Казуальные игры»). Второй жанр: «Раннер / гиперказуальная».

### Теги (выбираются из списка RuStore, 3–5 штук)
Аркада · Казуальная игра · Космос · Раннер · Одна рука / короткие сессии · Офлайн

### Возрастной рейтинг
**6+** — обоснование: нет насилия, крови, текста и азартных механик; есть реклама (баннер, видео за награду,
заставка при запуске) и «продолжение забега за рекламу». Реклама — единственная причина не ставить 0+:
маркировка должна учитывать рекламный контент.

## 3. Медиа

### Иконка
`icon_512.png` — 512×512, PNG, RGB (без альфа-канала), 118 КБ. Требования RuStore выполнены:
фон залит по всей площади, по краям нет прозрачности, читается в мелком размере (звёздочка + орбиты + комета).
Рекомендация RuStore — не ставить текст на иконку; здесь его и нет.

### Скриншоты
Требования: PNG/JPG, до 3 МБ, сторона 320–3840 px, рекомендуется 9:16 (1080×1920), минимум 3, максимум 10.
В наборе **8 штук 1080×1920**, все < 600 КБ, системные панели и рекламные баннеры срезаны.

Порядок подобран так, чтобы первые два кадра сразу показывали геймплей, а не меню:

| # | Файл | Что на экране |
|---|---|---|
| 1 | `01_gate.png` | врата из красных барьеров и кристаллы — главная механика |
| 2 | `02_powers.png` | все три усиления: щит, магнит, замедление + комбо ×1 |
| 3 | `03_ring.png` | сжимающееся кольцо — вторая угроза |
| 4 | `04_play_hints.png` | подсказки «внутрь / наружу» и бонусы «впритирку» (+40 ×3) |
| 5 | `05_meteors.png` | метеоритный дождь и общая картина забега |
| 6 | `06_menu.png` | главное меню: PLAY, кометы, подарок, +40 |
| 7 | `07_skins.png` | магазин восьми комет |
| 8 | `08_over.png` | экран результата: счёт 1234, новый рекорд, продолжение |

Вариант с подписями (5 файлов, `screenshots-captioned/`) — если хочется «продающих» кадров:

1. «Облетай красные барьеры — опасность видна заранее»
2. «Щит, магнит и замедление времени»
3. «Кольца сжимаются — держи дистанцию»
4. «Левая половина экрана — внутрь, правая — наружу»
5. «Метеоритные дожди и комбо до x5»

Использовать можно только один набор: в одной карточке нельзя смешивать стили.

### Видео (необязательно)
RuStore поддерживает промо-видео. Если понадобится — проще всего записать 15–20 секунд экрана телефона
в режиме забега (сцены `gate`, `powers`, `meteors` уже есть как debug-сцены).

**Ссылки для карточки RuStore:**

Для Pages нужно один раз включить: репозиторий → **Settings → Pages → Source: GitHub Actions**

**Важно (частая причина отказа):** RuStore требует, чтобы политика была доступна не только в карточке,
но и внутри приложения. Сейчас в «Настройках» такой ссылки нет — это правка на ~30 строк кода
(`Prefs` + экран настроек + `Intent.ACTION_VIEW`). Могу добавить отдельным коммитом.

## 5. Пошагово в консоли RuStore

1. Консоль → **Приложения → Добавить приложение**.
2. package name: `com.kirillpetrov.orbita` (после создания не меняется).
3. Загрузить `orbita-release.apk` из релиза build-6.
4. Вкладка «Карточка»: название, краткое и полное описание — из `texts/`.
5. Медиа: `icon_512.png` + 8 скриншотов из `screenshots/` в указанном порядке.
6. Категория «Игры → Аркады», теги, возрастной рейтинг **6+**.
7. Признаки: «содержит рекламу» — да, покупок нет.
8. Ссылка на политику конфиденциальности + контакты разработчика.
9. «Отправить на модерацию». Срок обычно до 72 часов; тестовый доступ не нужен — входа в приложении нет.

Отдельно стоит проверить сборку на живом телефоне до отправки: игра должна запускаться,
крутить баннер вне забега и не падать при выключенной сети (сейчас баннер ретраится, но проверить стоит).

## 6. Что проверить, чтобы не отклонили

* Иконка без прозрачности и с фоном по краям — ок (`icon_512.png`).
* ≥3 скриншотов, все показывают реальный интерфейс, без чужих логотипов и рамок устройств — ок.
* На скриншотах не должно быть рекламного баннера и системных панелей — срезаны.
* Язык карточки русский, тексты на скриншотах читаемы — **см. п. 7 про английский HUD**.
* Политика открывается по ссылке — да; ссылку внутри приложения ещё нужно добавить (см. п. 4).
* Разрешения обоснованы (только интернет для рекламы) — ок.
* Нет обещаний «лучшая игра», «топ-1», кликбейта — в текстах нет.
* Возрастная маркировка соответствует контенту рекламы — 6+.
* Подпись APK та же, что в следующих обновлениях (ключ в секретах GitHub) — не потерять.

## 7. Известный пробел: интерфейс на скриншотах — английский

Снимки сделаны на эмуляторе с локалью en-US, поэтому HUD («PLAY», «COMETS», «INWARD / OUTWARD»)
на английском. Интерфейс приложения локализован, так что на телефоне с русской локалью будет русский.
Формально RuStore требует русский текст на скриншотах, поэтому лучше перегенерировать.

Как получить русский набор:

1. GitHub → Actions → **Emulator screenshots** → Run workflow → ветка **`arena/257086d4-game`**.
   В `tools/emu_test.sh` уже включены русская локаль и 1080×1920 без системных панелей.
2. Либо локально: `bash tools/emu_test.sh` на подключённом устройстве/эмуляторе.
3. Затем: `python3 tools/make_rustore_screens.py shots` (нужны `pillow`, `numpy`) — скрипт срежет баннер
   и системные панели, приведёт кадры к 1080×1920 и соберёт подписи.
4. Готовое положить в `store/rustore/screenshots/`.

Скрипт также умеет собирать набор с подписями — `store/rustore/screenshots-captioned/`.
