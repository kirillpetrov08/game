# Орбита (Orbita) — неоновый забег по орбитам

Оригинальная казуальная игра для Android на Kotlin. Игрок — комета на одной из четырёх орбит вокруг звезды.
Касание **левой** половины экрана — переход на орбиту ближе к центру, **правой** — дальше.
Нужно собирать кристаллы, уворачиваться от красных барьеров и метеоров и ловить щиты.

## Геймплей
- 4 орбиты, плавные переходы между ними, хвост кометы, частицы, тряска экрана при столкновении.
- Барьеры предупреждают о появлении (пульсирующий контур) и не включаются, пока игрок внутри зоны — честная сложность.
- Метеоры летят от края к центру, заранее отмечены на краю экрана.
- Комбо-множитель до x5, щит (спасает от одного удара), уровни каждые 15 секунд.
- Магазин «Комет»: 6 скинов за кристаллы, один радужный.
- Русский и английский язык (по языку системы), звук и музыка с выключателями.

## Реклама (РСЯ, Yandex Mobile Ads SDK 8.6.0)
| Блок | ID | Где показывается |
|---|---|---|
| Баннер (adaptive sticky) | `R-M-20302673-1` | постоянно внизу экрана, вне игрового поля |
| Видео с наградой | `R-M-20302673-2` | «Продолжить» после проигрыша (1 раз за забег) и «+40 кристаллов» в меню |
| Реклама при открытии | `R-M-20302673-3` | после заставки (со 2-го запуска) и при возврате из фона после 30+ секунд, не чаще раза в 2 минуты |

В **debug**-сборке используются демо-блоки Яндекса, в **release** — ваши реальные ID (`Ads.kt`, объект `AdIds`).
Никогда не кликайте по собственной рекламе в release-сборке.

Чтобы блоки заработали, в кабинете РСЯ у приложения нужно **добавить ссылку на приложение** (ссылка RuStore после публикации) —
пока приложение в «тестовом статусе», показы могут быть ограничены.

## Сборка
Сборка идёт в GitHub Actions (`.github/workflows/build.yml`): на каждый push в `main` собираются
подписанные `orbita-release.apk` и `orbita-release.aab`, они публикуются на странице **Releases**.

Подпись берётся из секретов репозитория `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`.
**Сохраните файл ключа и пароль в надёжном месте** — без того же ключа вы не сможете выпускать обновления.

Локально: `./gradlew assembleRelease bundleRelease` (JDK 17, Android SDK 35). Без переменных окружения
`KEYSTORE_*` release подписывается debug-ключом (для проверки, не для публикации).

`tools/gen_assets.py` генерирует звуки, музыку и иконки (numpy, pillow).
`.github/workflows/screens.yml` запускает игру в эмуляторе и делает скриншоты экранов.

## Публикация в RuStore
Всё для карточки лежит в **`store/rustore/`**, инструкция — **[`store/rustore/CARD.md`](store/rustore/CARD.md)**.
Там готовые тексты (`texts/`), иконка 512×512, скриншоты 1080×1920 (`screenshots/`) и политика
конфиденциальности (`privacy-policy-ru.md`).

1. Консоль RuStore → «Добавить приложение» → загрузить `orbita-release.apk` (или `.aab`) со страницы Releases.
2. Заполнить карточку по `store/rustore/CARD.md`: название, описания, категория «Игры → Аркады», 6+.
3. Иконка и скриншоты — из `store/rustore/`.
4. Политика конфиденциальности: опубликовать `privacy-policy-ru.md` по публичному URL и указать в карточке
   (реклама собирает рекламный идентификатор — это описано в политике).
5. После публикации добавьте ссылку RuStore в кабинете РСЯ у приложения (id 20302673).

Скриншоты для карточки пересобираются так: workflow **Emulator screenshots** (или `tools/emu_test.sh`)
делает снимки 1080×1920 с русской локалью, затем `python3 tools/make_rustore_screens.py shots`
срезает баннер и системные панели и раскладывает кадры в `store/rustore/screenshots/`.

`applicationId`: `com.kirillpetrov.orbita` — при желании поменяйте в `app/build.gradle.kts` **до первой публикации**.
